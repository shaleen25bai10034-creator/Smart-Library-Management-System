# Project Statement

## Project Title
Smart Library Management System

## Problem Statement
Manual library management can make it difficult to track books, users, issue/return operations, availability, and overdue fines efficiently. The project proposes a Java-based application to organize these operations through a simple, modular system.

## Scope
The application manages books and users, supports searching, issuing and returning books, calculates overdue fines, and records transactions. It is designed as a console application for academic demonstration.

## Target Users
- Students/library members
- Librarians
- Academic evaluators

## High-Level Features
- Add and view books
- Search books
- Register and view users
- Issue books
- Return books
- Calculate fines
- Maintain transaction history
- Handle invalid input and operational errors
